# GP Location Tracker Report Automation

A production-ready desktop automation utility designed to eliminate manual data entry by instantly formatting raw data exports into corporate templates.

## 📌 Project Overview
This tool completely automates the tedious process of extracting data from raw GP Location Tracker exports and mapping them directly into a standardized corporate reporting layout. Built during my operations internship at HB Jamil Group, it bridges the gap between raw data collection and executive reporting.

## 🚀 Key Features
- **Zero Configuration Run:** Packaged as an independent executable (`.exe`) allowing non-technical staff to run the script with a single click.
- **Folder-to-Folder Pipeline:** Monitors an incoming directory for raw data drops and instantly outputs fully stylized, presentation-ready spreadsheets.
- **99% Efficiency Increase:** Successfully compressed a daily operational task taking **3+ hours down to under 60 seconds**.
- **Data Safeguards:** Eliminates human copy-paste risks during heavy daily bulk data handling.

## 🛠️ Tech Stack & Architecture
- **Core Engine:** Python
- **Distribution:** Standalone Executable Binary (`.exe`)
- **Development Methodology:** AI-Assisted Architecture Design & Advanced Prompt Engineering

## 📁 Recommended Operational Structure
To run the automation effectively, ensure the executable sits alongside these local directories:
- `Incoming/` (Drop raw tracker export files here)
- `Templates/` (Contains the target master layout spreadsheet)
- `Output/` (Where finalized automated files appear instantly)
